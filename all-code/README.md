# hh

This project is a static multi-page site for chemistry study materials and an AI assistant.

## Deploy

### Netlify
1. Sign in at https://netlify.com
2. Drag and drop this folder into Netlify, or connect the GitHub repository.
3. Deploy.

The site will be published as a static site automatically.

### Vercel
1. Import the GitHub repository at https://vercel.com
2. Set the root directory to the repository root.
3. Deploy.
